# Event Page Design Reference

## Overview (from design images)

### Hero Section (Dark Background)
- Back to Events link at top
- Left: Image slider with navigation dots and arrows, captions on images
- Right: Event info
  - Type badge (e.g., "Conference") + Date badge
  - Event title (large)
  - Subtitle/tagline
  - Location + Time info
  - Stats row: 4 stat cards (Attendees, Investors, Startups, Countries)
  - Green "Book Tickets" button (full width)
  - Share button

### Tab Navigation (6 tabs)
1. Overview
2. Schedule
3. Speakers
4. Tracks
5. What to Expect
6. Side-Events

### Right Sidebar (consistent across all tabs)
- Event Details card (Dates, Venue, Organizer)
- Book Tickets button (green)
- Visit Website button (outline)
- Advertisement placeholder (300x250)
- TechScoop Coverage (related articles)
- Event Sponsors (logo grid)

---

## Tab 1: Overview
- **About This Event**: Full description paragraph
- **Featured Speakers**: Horizontal carousel with avatar, name, title, company
- **Event Tracks**: Horizontal scroll with icon + name + description cards
- **TechScoop Coverage**: Horizontal scroll of article cards (image, category badge, title, read time)

---

## Tab 2: Schedule
- **Day tabs**: Day 1 (March 15, 2026), Day 2, Day 3
- **Timeline view**: Each session shows:
  - Time (left column): Start time, End time
  - Session card:
    - Track badge (top, colored)
    - Session title (bold)
    - Description
    - Speaker avatars + names
    - Location badge (right side)

---

## Tab 3: Speakers
- **Featured Speakers**: Large cards with:
  - Photo (large, rectangular)
  - "Featured" badge
  - Name, Title, Company
  - Bio paragraph
- **All Speakers**: Grid of smaller cards with:
  - Avatar (circular)
  - Name, Title, Company

---

## Tab 4: Tracks
- **Header**: "One Event, Content for Everyone"
- **Subtitle**: "Six specialized tracks covering the most important topics in technology."
- **Track Cards** (3x2 grid):
  - Colored top border
  - Icon
  - Track name (bold)
  - Short description
  - Longer description paragraph
  - "View sessions →" link

---

## Tab 5: What to Expect
- **Header**: "What to Expect"
- **Subtitle**: "Everything waiting for you at MENA Tech Summit 2026."
- **Feature Cards** (3x2 grid):
  - Icon
  - Feature name (bold)
  - Description
- Features: Keynote Presentations, Masterclasses & Workshops, Startup Exhibitions, Investor Matchmaking, Networking Events, Awards Ceremony
- **The Venue Section**:
  - Venue image (left)
  - Venue name, address (right)
  - "Get Directions" link

---

## Tab 6: Side-Events (from image 6)
- Event cards with:
  - Image
  - Event name
  - Date/time
  - Location
  - RSVP button

---

## CTA Section (bottom, before footer)
- Green background
- "Ready to join the tech community?"
- Subtitle text
- Two buttons: "Book Tickets" (outline) + another button

---

## Color Scheme
- Primary: Green (#22c55e or similar)
- Dark hero: Near black (#1a1a1a)
- Cards: White background
- Track badges: Various colors (teal, blue, purple, orange, pink, yellow)

---

## Typography
- Headings: Bold, clean sans-serif
- Body: Regular weight
- Stats: Large numbers with small labels below
